# 字节跳动 · 前端开发工程师

**工作地点**：北京 / 上海 / 杭州 / 深圳  
**招聘部门**：抖音电商 / 飞书 / 今日头条 / 国际化电商（可根据实际投递选择）

---

## 职位描述

1. 负责字节跳动核心业务（如抖音电商、飞书、今日头条等）的前端架构设计、功能开发与性能优化  
2. 参与大型前端工程化体系建设，推动组件库、脚手架、自动化构建等基础设施的完善  
3. 与产品、设计、后端紧密协作，保障高并发场景下的用户体验与稳定性  
4. 探索前沿技术（WebAssembly、微前端、Serverless 等），解决业务痛点并落地  
5. 指导初级工程师，参与团队技术分享与代码评审

---

## 职位要求

### 基础能力
- 本科及以上学历，计算机相关专业，3 年以上前端开发经验  
- 扎实的计算机基础：数据结构、算法、网络协议（HTTP/HTTPS、WebSocket）  
- 精通 HTML5 / CSS3 / JavaScript (ES6+)，熟悉 TypeScript  
- 熟练使用至少一种主流前端框架：**React**（优先）或 Vue，并理解其底层原理（虚拟 DOM、diff 算法、响应式机制）

### 工程化能力
- 熟悉 Webpack / Vite / Rollup 等构建工具，能进行深度配置优化  
- 了解前端性能监控与优化手段（Core Web Vitals、首屏加载、内存泄漏排查）  
- 熟悉 Git 工作流，有 CI/CD（GitHub Actions / GitLab CI / Jenkins）实践经验

### 软技能
- 良好的沟通协作能力，能推动方案落地  
- 有技术热情，持续关注前端社区动态，乐于分享

---

## 加分项

- 有大型复杂项目（如低代码平台、在线文档、实时协作系统）开发经验  
- 熟悉 Node.js（Express / Koa / Nest.js）或后端语言（Go / Python）  
- 有 WebAssembly、WebGL、Canvas 或富文本编辑器相关经验  
- 活跃于 GitHub，有高质量开源项目或技术博客  
- 英语流利，能阅读英文技术文档并进行基本口语交流

---

## 面试流程

1. 简历筛选（3 个工作日内反馈）  
2. 笔试（可选，视简历情况）  
3. 技术一面（基础 + 框架原理）  
4. 技术二面（工程化 + 项目深挖）  
5. 技术三面 / 交叉面（架构设计 + 软素质）  
6. HR 面

> 面试支持全程线上（飞书会议），结果一般在面试后 3-5 天通知。
